# Challenge 1 — Vocabulary Master
## Recognition

### 1. Nhìn màu → chọn từ

1. 🟥 → `red / blue / green / yellow`
2. 🟦 → `brown / blue / black / pink`
3. 🟨 → `yellow / white / orange / purple`
4. 🟩 → `green / red / brown / blue`
5. 🟫 → `pink / brown / yellow / black`
6. 🟪 → `purple / orange / green / white`
7. 🟧 → `blue / orange / pink / red`
8. ⬛ → `black / brown / white / purple`
9. ⬜ → `yellow / white / pink / green`
10. 🩷 → `pink / red / purple / orange`

### 2. Nghe → chọn từ

Người lớn đọc một từ trong PDF. Bé chọn đúng từ.

1. `red / green / brown / blue`
2. `yellow / purple / black / pink`
3. `orange / white / blue / brown`
4. `green / pink / red / black`
5. `purple / yellow / orange / white`

### 3. Nhìn hình → chọn cụm từ

1. 🖼️ tàu màu đỏ  
   `a blue ball / a red train / a green yo-yo / a brown teddy bear`

2. 🖼️ bóng màu xanh dương  
   `a red train / a blue ball / a brown teddy bear / a green yo-yo`

3. 🖼️ gấu bông màu nâu  
   `a green yo-yo / a brown teddy bear / a blue ball / a red train`

4. 🖼️ yo-yo màu xanh lá  
   `a brown teddy bear / a red train / a green yo-yo / a blue ball`

### 4. Chữ cái → ghép từ

- A a → `apple / bird / cat / dog`
- B b → `dog / bird / apple / cat`
- C c → `bird / dog / cat / apple`
- D d → `cat / apple / dog / bird`

# Challenge 2 — Listen & Understand
## Recognition

### 1. Nghe → chọn nghĩa

1. **Come here.**  
   - [ ] Lại đây.
   - [ ] Quay lại.

2. **Turn around.**  
   - [ ] Lại đây.
   - [ ] Quay lại.

3. **What color is it?**  
   - [ ] Nó màu gì?
   - [ ] Nó là gì?

4. **What is it?**  
   - [ ] Nó là gì?
   - [ ] Nó màu gì?

5. **See you later.**  
   - [ ] Hẹn gặp lại.
   - [ ] Xin chào.

### 2. Nghe → chọn câu đúng

Người lớn đọc câu in đậm.

**It's red.**
- [ ] It's blue.
- [ ] It's red.
- [ ] It's purple.

**It's blue.**
- [ ] It's green.
- [ ] It's blue.
- [ ] It's brown.

**It's purple.**
- [ ] It's purple.
- [ ] It's orange.
- [ ] It's pink.

**It's a green car.**
- [ ] It's a red train.
- [ ] It's a green car.
- [ ] It's a blue ball.

### 3. Nghe lời chào → chọn phản hồi có trong bài

**Hi, boys and girls.**
- [ ] Hello, Miss Jones.
- [ ] It's purple.
- [ ] Turn around.

**Good-bye.**
- [ ] See you later.
- [ ] What color is it?
- [ ] Come here.

### 4. Nghe → thực hiện

Người lớn đọc ngẫu nhiên:

- Come here.
- Turn around.

Bé thực hiện đúng hành động.
